# Phase 5 Strategy Report Template

Use this template when a strategy is reviewed for live-readiness or capital allocation changes. All timestamps
must be UTC, all finance metrics must be Decimal/Numeric-derived strings, and every live-readiness decision must
be traceable to append-only `audit_logs`.
