# Strategy Research Report Template / 策略研究报告模板

Use this template to make experiments reproducible and distinguish measured results from assumptions. All timestamps are UTC; finance metrics use Decimal/Numeric-derived values. Keep private account data out of published reports.

The optional `build_strategy_report_markdown(...)` generator accepts backtest evidence, comparison summaries, and audited configuration changes. Its field names describe software diagnostics, not a profitability guarantee or permission to trade.

- Parameter reference: <StrategyRun.parameters or artifact path>
- Code revision: <commit>
- Generated at: <UTC datetime>
- Generated by: <actor>

- Data sources and access conditions: <providers, permissions>
- Sample window: <UTC start> to <UTC end>
- Train/validation/test split: <independent chronological split>
- Sample count and missing data: <counts, gaps>
- Model and calibration artifacts: <versions, or not used>
- Costs, slippage, and execution assumptions: <values and method>
- Feature leakage check: `compute_features(...)` strict `< timestamp`
- Bar-by-bar validation: <method and evidence reference>
